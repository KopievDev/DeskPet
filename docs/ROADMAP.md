# DeskPet — roadmap

Настольный AI-компаньон для **LILYGO T-Display-S3 / ESP32-S3**. Принципы: offline-first, приватность по умолчанию, модульная прошивка, работа с iPhone, Android и Mac.

> Номера версий ниже — план разработки, не выпущенные релизы. Очерёдность после 0.1 можно корректировать после проверки платы.

## 0.1 · Animated Face (PR #1)
- [x] Аппаратный профиль обычной T-Display-S3, LCD 320×170, ландшафтная ориентация.
- [x] Глаза, зрачки, моргание, самостоятельные движения взгляда.
- [x] Пять эмоций: neutral / happy / curious / surprised / sleepy.
- [x] Сон, реакция на две встроенные кнопки, Serial-команды.
- [x] Off-screen sprite в PSRAM для снижения мерцания.
- [ ] Подтвердить компиляцию PlatformIO на Mac.
- [ ] Проверить экран, обе кнопки, FPS и память на физической плате.

## 0.2 · Bluetooth LE foundation
- [ ] BLE-стек на ESP32-S3: advertising, подключение, обработка отключения и переподключения.
- [ ] Безопасное сопряжение с iPhone/Android (bonding, шифрование, явное подтверждение на устройстве).
- [ ] Хранение доверенных устройств, удаление пары / factory reset, защита от подключения чужих телефонов.
- [ ] Версионированный формат событий (уведомление, вызов, состояние, важность, время, источник) с ограничением размера payload.
- [ ] Очередь уведомлений и корректная работа UI при потерянном соединении.
- [ ] Измерение RAM/PSRAM, FPS, стабильности соединения и энергопотребления при BLE + LCD.

## 0.3 · iPhone notifications (Apple ANCS)
- [ ] Исследовать и реализовать **Apple Notification Center Service (ANCS)**: DeskPet как BLE-клиент ANCS после сопряжения с iPhone.
- [ ] Подписка на события уведомлений, получение доступных атрибутов (приложение, заголовок, сообщение, дата, флаги).
- [ ] Новые/изменённые/удалённые уведомления; категория входящего вызова, если её предоставляет iOS.
- [ ] Экран уведомления: компактная карточка, прокрутка/переключение кнопками, тайм-аут и возврат к глазам.
- [ ] Эмоции для входящего вызова, сообщений, напоминаний и важных уведомлений.
- [ ] Учитывать ограничения iOS: выдача атрибутов и содержимого зависит от разрешений и настроек приватности; поддержка произвольных ответов на сообщения не гарантируется.
- [ ] Проверка на реальном iPhone: initial pairing, repeated reconnect, блокировка экрана, режимы Focus и скрытые превью.
- [ ] Проверить работу без фонового iOS-приложения: ANCS задуман для Bluetooth-аксессуаров.

## 0.4 · Android notifications
- [ ] Минимальное Android-приложение-компаньон для сопряжения и настройки DeskPet.
- [ ] Получение уведомлений с **NotificationListenerService** после отдельного системного разрешения пользователя.
- [ ] Передача отфильтрованных событий на DeskPet по BLE GATT с повторным подключением.
- [ ] Allowlist/denylist приложений, режим «только факт уведомления», настройка скрытия текста.
- [ ] Вызовы, сообщения, письма и календарь: нормализация полей, без предположений о содержимом у всех приложений.
- [ ] Проверить работу в фоне и ограничения производителя/версии Android (Companion Device Manager / подходящий foreground service при необходимости).
- [ ] Не хранить историю уведомлений на телефоне или устройстве по умолчанию.

## 0.5 · Wi-Fi, macOS & device management
- [ ] Wi-Fi provisioning без секретов в исходном коде.
- [ ] Безопасное локальное обнаружение и сопряжение с macOS, локальная связь по WebSocket с аутентификацией.
- [ ] Версионирование протокола, heartbeat, reconnect, защита от повторных событий.
- [ ] SwiftUI menu bar app: состояние DeskPet, эмоции, настройки и тестовые команды.
- [ ] Начальная **виртуальная версия питомца на Mac**: те же глаза/эмоции в отдельном компактном окне, без обязательной покупки устройства; продумать отображение поверх рабочего стола, скрытие и режим ненавязчивого присутствия.
- [ ] Xcode/build/PR уведомления (после согласия пользователя), Pomodoro, режим «не беспокоить».
- [ ] OTA с проверкой подлинности прошивки и восстановлением при неудачном обновлении.
- [ ] Одновременная работа Wi-Fi и BLE: проверить coexistence и поведение при обрывах каналов.

## 0.6 · AI Gateway & Chat
- [ ] Provider interface для OpenAI / Gemini / Ollama и настраиваемого совместимого провайдера.
- [ ] Ключи только в защищённом хранилище приложения/шлюза, **не в ESP32**.
- [ ] Текстовый чат, история только по согласию, просмотр/удаление истории.
- [ ] Tool calling с allowlist, пользовательскими правами и подтверждением чувствительных действий.
- [ ] Структурированные эмоции и мимика ИИ: валидация допустимых команд на устройстве.
- [ ] Локальный режим работы персонажа, когда Gateway недоступен.
- [ ] **Установка локальной LLM из приложения в один клик**: рекомендации по памяти Mac, выбор небольшой модели, загрузка с прогрессом, остановка/удаление моделей.
- [ ] Первая интеграция с Ollama без обязательной ручной настройки; оценить MLX Swift как встроенный движок на Apple Silicon.
- [ ] Политика экономии памяти: lazy loading, авто-выгрузка модели, настраиваемое время удержания, режимы «экономия / баланс / скорость»; показать RAM и размер модели.
- [ ] Общий интерфейс AI-движка для виртуального питомца на Mac и физического DeskPet.

## 0.7 · Voice

- [ ] Потоковое STT/TTS/Realtime через Gateway по Wi-Fi; учитывать задержку и разрывы.
- [ ] Никакого постоянного сохранения аудио по умолчанию.
- [ ] Анимации «слушаю / думаю / говорю», возможность прервать озвучивание.
- [ ] **MVP Voice Preview на Mac**: прослушивание тестовой фразы через системный синтезатор macOS без подключённой платы, выбор доступного голоса и скорости.
- [ ] Отделить **STT (речь → текст)**, **LLM (текст → ответ и эмоции)**, **TTS (текст → речь)** и **Audio Output (Mac / DeskPet)** для независимого выбора провайдеров.
- [ ] Одинаковый выбранный голос у DeskPet Virtual и физического устройства: озвучка генерируется на Mac/AI Gateway, на ESP32 передаётся подготовленный аудиопоток.
- [ ] Первые эмоции голоса (радость, сонливость, удивление, сарказм) с fallback на обычный TTS, если движок не поддерживает выразительную речь.

## 1.0 · Personality Studio (характер питомца)
- [ ] **Редактор характера** в macOS-приложении (позже — на телефоне): дружелюбие, сарказм, юмор, дерзость, эмоциональность, болтливость, инициативность.
- [ ] Настройка **ненормативной лексики**: Выкл. (по умолчанию) / Лёгкая / Умеренная / Без цензуры — только по явному выбору пользователя.
- [ ] Отдельные переключатели **«Мат в чате»** и **«Мат вслух»**; быстрый безопасный режим, например для офиса или присутствия детей.
- [ ] Пресеты: Милашка, Ассистент, Хулиган, Бес, Гений, Геймер, Custom; возможность создать, сохранить, экспортировать и импортировать профиль.
- [ ] Пользовательское описание характера (prompt) с предпросмотром тестовых реплик и объяснением, что провайдеры ИИ могут ограничивать стиль речи.
- [ ] Контекстные реакции: ошибка сборки, успешный PR, напоминание о перерыве, поглаживание, входящий вызов — характер влияет на фразы, эмоции и движения, а не только на текст.
- [ ] Единая типизированная схема **PersonalityProfile** (версия, настройки речи, мимики, голосового режима, инициативности) с валидацией и миграциями.
- [ ] Характер применяется и к облачным, и к локальным моделям; гарантировать стиль/бранную лексику невозможно — это зависит от модели и голосового движка.
- [ ] Пользовательские инструкции изменяют тон, **но не разрешения**: все внешние действия идут через allowlist, подтверждения и контроль приватности.

- [ ] Режимы: закрепить поверх окон / скрыть / только строка меню / автоматически скрывать во время полноэкранной работы.
- [ ] Общие компоненты с физическим устройством: **PersonalityProfile**, логика состояний и реакций, AI Gateway, интеграции, задачи и настройки.
- [ ] **«Переезд» питомца** между Virtual и Hardware: сохранение профиля, имени, пользовательских настроек и разрешённой памяти; один активный ведущий экземпляр, согласованность состояния без дублей уведомлений.
- [ ] Общие чат и история по согласию; явное локальное хранение, экспорт/удаление данных, понятная индикация использования облачных моделей.
- [ ] Виртуальный питомец работает полностью локально без устройства; физический продолжает базовые анимации и уведомления без Mac.
- [ ] Подготовить отдельную сборку/демо **DeskPet Virtual** для проверки спроса до производства железа.
- [ ] Исследовать коммерческую модель: бесплатный базовый виртуальный питомец, опциональные платные персональности/функции, совместимость с DIY и готовыми устройствами.

## 1.2 · Voice Studio (редактор голоса)
- [ ] Раздел **Voice Studio** в macOS-приложении: выбор голосового движка, персонажа и голосового пресета с моментальным **▶ Прослушать**.
- [ ] Предпрослушивание **без физического DeskPet**: ввод произвольной фразы, прослушивание через динамики Mac; кнопки «прослушать обычный / радостный / сонный / саркастичный / раздражённый».
- [ ] Концепты готовых голосов: **Deski** (дружелюбный), **Gremlin** (дерзкий), **Mochi** (милый), **Alfred** (спокойный), **Pixel** (электронный). Это целевые профили, а не обещание готовых синтезированных голосов.
- [ ] Настройка высоты и скорости речи, громкости, выразительности, характерности/«роботизированности» **в пределах возможностей конкретного TTS**; показывать недоступные настройки как неподдерживаемые.
- [ ] Независимая настройка **«Мат вслух»** и беззвучного режима, синхронизация с Personality Studio; осмысленный безопасный вариант по умолчанию.
- [ ] Единый интерфейс **TTSProvider** с локальными backend: **macOS Speech** (быстрый MVP), **Piper** (компактный offline), оценить **Qwen3-TTS 0.6B** (более выразительный) и **Qwen3-TTS 1.7B VoiceDesign** (создание голосового профиля).
- [ ] Исследовать **MLX-Audio** и альтернативные способы локального инференса на Apple Silicon: поддержка русского языка, качество/интонации, RAM, размер, задержка первого фрагмента, лицензии и совместимость моделей.
- [ ] Опциональный облачный TTS (например, OpenAI) **только с разрешения**; локальный режим не требует отправки текста в облако.
- [ ] Менеджер голосовых моделей **в один клик**: выбор, загрузка, прогресс, тестирование, остановка, удаление, объём диска/RAM и авто-выгрузка при простое.
- [ ] Голосовой профиль **VoiceProfile**: выбранный движок/модель/голос, настройки, пресет эмоций, версионирование и перенос между Mac и аппаратным DeskPet без смены голоса при переключении LLM.
- [ ] **Voice Design**: описать желаемый голос словами, сгенерировать тестовое звучание, сохранить пресет — при наличии подходящего движка и достаточных ресурсов.
- [ ] Эмоциональный пайплайн: LLM возвращает валидируемые **text + emotion + voiceStyle**, TTS подбирает интонацию, DeskPet синхронизирует глаза/движения с состояниями речи без блокировки кнопок и уведомлений.
- [ ] Аудиопоток Mac → ESP32-S3 по Wi-Fi: буферизация, контроль задержки, прерывание ответа, корректное восстановление после обрыва; тест с **INMP441 + MAX98357A** и дисплеем.
- [ ] Оптимизировать память: голос не обязан постоянно держать тяжёлый TTS в RAM; лёгкий fallback остаётся доступен при выгрузке нейросетевого движка.
- [ ] Проверить лицензию и коммерческое использование **каждой** выбранной модели голоса, движка и голосового набора отдельно.

## Acceptance criteria для Voice Studio

1. На Mac можно услышать выбранную русскоязычную тестовую фразу **до подключения ESP32**, без терминала и ручного развёртывания TTS.
2. Можно выбрать доступный голос, изменить скорость и сохранить выбор; неподдерживаемые возможности конкретного движка корректно отключены.
3. При наличии эмоционального TTS одна фраза воспроизводится с как минимум двумя различимыми интонациями; на базовом движке работает понятный fallback.
4. Голос сохраняется при переключении LLM (локальная/облачная), а тот же VoiceProfile используется DeskPet Virtual и физическим роботом.
5. Пользователь явно выбирает, передавать ли текст для облачной озвучки; локальные голоса работают без интернета после установки.
6. Переключение «Мат вслух» не влияет на текстовую настройку и не обходит ограничения выбранного TTS.
7. Отключение/удаление большой TTS-модели освобождает память, не ломает анимации и не мешает базовым функциям питомца.

## Acceptance criteria для Personality Studio и Virtual DeskPet

1. Новому пользователю по умолчанию назначен нейтральный характер без мата; ненормативная лексика включается отдельно для текста и голоса.
2. Характер меняет тон и анимации в тестовых сценариях, не отключая проверки команд и разрешений.
3. Пользователь может переключать пресеты и редактировать Custom-профиль, не теряя настройки после перезапуска.
4. DeskPet Virtual работает без ESP32, показывает эмоции и поддерживает локальный чат после установки модели.
5. При подключении физического DeskPet профиль и настройки синхронизируются без дублирования уведомлений; отключение устройства не ломает виртуального питомца.
6. Локальную модель можно скачать и удалить через интерфейс; при простое приложение умеет выгружать модель из памяти.

## Acceptance criteria для BLE-уведомлений

1. iPhone: после разрешённого сопряжения DeskPet получает поддерживаемые системой уведомления через ANCS **без интернета и без работающего на Mac Gateway**.
2. Android: с установленным приложением и выданным разрешением уведомления доставляются на DeskPet локально по BLE.
3. Уведомления не обрывают анимации и не блокируют управление; карточка автоматически исчезает.
4. После разрыва и восстановления соединения не происходит бесконечных повторов старых событий.
5. Чувствительное содержимое никогда не отправляется в AI без отдельного opt-in.
