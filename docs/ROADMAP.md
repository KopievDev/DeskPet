# DeskPet — roadmap

## 0.1 · Animated Face (этот PR)
- [x] Аппаратный профиль T-Display-S3, LCD 320×170, ландшафтная ориентация.
- [x] Глаза, зрачки, моргание, самостоятельные движения взгляда.
- [x] Пять эмоций: neutral / happy / curious / surprised / sleepy.
- [x] Сон, реакция на две встроенные кнопки, Serial-команды.
- [x] Off-screen sprite в PSRAM для снижения мерцания.
- [ ] Подтвердить компиляцию PlatformIO на Mac.
- [ ] Проверить экран, обе кнопки, FPS и память на физической плате.

## 0.2 · Connectivity
- [ ] Wi-Fi provisioning (без зашитых логинов/паролей).
- [ ] Локальное безопасное сопряжение с macOS по явному подтверждению.
- [ ] Протокол событий с версиями схемы, heartbeat, reconnect.
- [ ] OTA с проверкой подписей и защитой от неуспешного обновления.

## 0.3 · macOS application
- [ ] SwiftUI menu bar app + устройство/состояние/кастомизация.
- [ ] Xcode/build/PR уведомления только после согласия пользователя.
- [ ] Фокус-сессии, таймеры, режим не беспокоить.

## 0.4 · AI Gateway
- [ ] Единый provider interface для OpenAI / Gemini / Ollama.
- [ ] Безопасное хранение ключей в приложении/шлюзе, не на ESP32.
- [ ] Текстовый чат, история по согласию, очистка истории.
- [ ] Tool calling с allowlist, разрешениями и подтверждением опасных действий.
- [ ] Маппинг эмоций/мимики на разрешённые действия устройства.

## 0.5 · Voice & hardware
- [ ] I2S-микрофон, I2S-усилитель и динамик.
- [ ] Push-to-talk; физическое отключение микрофона и индикатор.
- [ ] Потоковое STT/TTS через gateway, без хранения аудио по умолчанию.
- [ ] 2 сервопривода головы с отдельным питанием и ограничениями.
- [ ] Датчики приближения, освещённости, температуры/влажности/CO₂.

## Later
- [ ] iOS app, BLE pairing, настройки.
- [ ] Home Assistant, сценарии, персональности, локальная память питомца.
- [ ] Смена платы/экрана без переписывания движка персонажа.
